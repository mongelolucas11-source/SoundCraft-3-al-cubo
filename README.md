##  ¿Qué es SoundCraft?

SoundCraft es una aplicación que funciona como una consola digital de sonidos. Permite reproducir diferentes efectos de audio mediante botones interactivos, organizados en distintas categorías.

Además, ofrece la posibilidad de incorporar sonidos personalizados, creando una biblioteca adaptada a las necesidades de cada usuario.

Su objetivo es facilitar el acceso, la organización y la reproducción de sonidos de manera rápida y sencilla.

---

## Funcionalidades principales

- **Biblioteca de sonidos:** colección de efectos de audio predeterminados.
- **Agregar sonidos:** posibilidad de incorporar archivos de audio propios.
- **Pads interactivos:** botones individuales para reproducir cada sonido.
- **Categorías:** organización de sonidos por tipo.
- **Buscador:** permite encontrar sonidos rápidamente.
- **Control de audio:** reproducción, pausa y detención.
- **Personalización:** organización visual de los sonidos.

## Identidad visual

La aplicación utiliza una estética moderna y tecnológica, inspirada en las consolas de producción musical.

**Paleta cromática:**
- Negro: fondo principal.
- Gris oscuro: superficies y controles.
- Celeste y turquesa: elementos destacados.
- Naranja, violeta, verde y rojo: identificación de categorías.

**Estilo gráfico:** minimalista, dinámico e intuitivo.
